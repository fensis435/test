EKS Pod Identity の環境で、AWS Secrets Manager からシークレットを取得・同期するための **`ClusterSecretStore`** と **`ExternalSecret`** のマニフェスト例です。

---

### 1. ClusterSecretStore の定義

`ClusterSecretStore` は、クラスタ全体で利用できる SecretStore です。
Pod Identity を利用する場合、AWS SDK のデフォルト認証チェーンが自動で認証情報を読み込むため、`auth` ブロックで明示的なアクセスキーや IAM ロール（IRSA）を指定する必要はありません。

```yaml
apiVersion: external-secrets.io/v1beta1
kind: ClusterSecretStore
metadata:
  name: aws-secretsmanager
spec:
  provider:
    aws:
      service: SecretsManager
      region: ap-northeast-1
      # Pod Identity を利用する場合、AWS SDK が環境変数を自動参照するため
      # auth セクションの記述は不要です。

```

---

### 2. ExternalSecret の定義

Secrets Manager に保存されているデータ形式（JSON形式かプレーンテキストか）や、同期方法に応じて使い分けます。

#### パターン A: JSONから特定のプロパティ（キー）だけを個別に取得する場合 (`data`)

Secrets Manager に `my-app/db-credentials` という名前で以下の JSON が保存されている場合の例です。

```json
{
  "username": "admin",
  "password": "SuperSecretPassword123!"
}

```

```yaml
apiVersion: external-secrets.io/v1beta1
kind: ExternalSecret
metadata:
  name: db-credentials-es
  namespace: default
spec:
  refreshInterval: "1h" # 1時間ごとに Secrets Manager と同期
  secretStoreRef:
    name: aws-secretsmanager
    kind: ClusterSecretStore
  target:
    name: db-credentials-k8s # 作成される Kubernetes Secret の名前
    creationPolicy: Owner
  data:
    - secretKey: DB_USER # K8s Secret のキー名
      remoteRef:
        key: my-app/db-credentials # Secrets Manager のシークレット名 (または ARN)
        property: username         # JSON 内のプロパティ名
    - secretKey: DB_PASS
      remoteRef:
        key: my-app/db-credentials
        property: password

```

#### パターン B: JSONのすべてのキー・バリューを丸ごと同期する場合 (`dataFrom`)

Secrets Manager 内の JSON キーをそのまま Kubernetes Secret のデータとしてまとめて展開したい場合は `dataFrom.extract` を使用します。

```yaml
apiVersion: external-secrets.io/v1beta1
kind: ExternalSecret
metadata:
  name: db-credentials-bulk-es
  namespace: default
spec:
  refreshInterval: "1h"
  secretStoreRef:
    name: aws-secretsmanager
    kind: ClusterSecretStore
  target:
    name: db-credentials-k8s
    creationPolicy: Owner
  dataFrom:
    - extract:
        key: my-app/db-credentials # JSON 全体がそのまま K8s Secret の key/value に展開される

```

---

### 注意点：IAM ポリシーの設定

ESO の Pod（`external-secrets`）に紐付けた IAM ロールに、Secrets Manager への読み取り権限が含まれていることを確認してください。

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "secretsmanager:GetSecretValue",
        "secretsmanager:DescribeSecret"
      ],
      "Resource": "arn:aws:secretsmanager:ap-northeast-1:<ACCOUNT_ID>:secret:my-app/*"
    }
  ]
}

```
