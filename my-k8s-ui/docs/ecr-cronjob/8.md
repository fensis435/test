EKS Pod Identity 前提で External Secrets Operator (ESO) を導入する手順は以下の **4 ステップ** です。Pod Identity を利用することで、ServiceAccount への IRSA（`[eks.amazonaws.com/role-arn](https://eks.amazonaws.com/role-arn)`）アノテーションの付与が不要になります。

1. **IAM ロールとポリシーの作成:**
ESO の Pod に付与する IAM ロールを作成します。信頼関係（Trust Policy）のプリンシパルには `pods.eks.amazonaws.com` を指定します。

**信頼ポリシー（Trust Policy）:**

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": {
        "Service": "pods.eks.amazonaws.com"
      },
      "Action": [
        "sts:AssumeRole",
        "sts:TagSession"
      ]
    }
  ]
}

```

**アクセス許可ポリシー（IAM Policy）の例 (ECR トークンを取得する場合):**

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "ecr:GetAuthorizationToken"
      ],
      "Resource": "*"
    }
  ]
}

```

※ AWS Secrets Manager や SSM Parameter Store も利用する場合は、必要に応じて `secretsmanager:GetSecretValue` や `ssm:GetParameters` などの権限を追加してください。


2. **Pod Identity 関連付け（Association）の作成:**
作成した IAM ロールと、ESO が作成する Kubernetes の ServiceAccount (`external-secrets/external-secrets`) を紐付けます。

```bash
aws eks create-pod-identity-association \
  --cluster-name <YOUR_CLUSTER_NAME> \
  --namespace external-secrets \
  --service-account external-secrets \
  --role-arn arn:aws:iam::<YOUR_ACCOUNT_ID>:role/<YOUR_ESO_ROLE_NAME>

```


3. **Helm による ESO のインストール:**
Helm を使って ESO をインストールします。Pod Identity の認証用環境変数は EKS によって自動注入されるため、Helm の値指定でアノテーションを設定する必要はありません。

```bash
# チャートリポジトリの追加
helm repo add external-secrets https://charts.external-secrets.io
helm repo update

# インストール実行
helm install external-secrets external-secrets/external-secrets \
  --namespace external-secrets \
  --create-namespace \
  --set installCRDs=true

```


4. **動作確認用リソースの設定 (ECRトークン自動同期の例):**
ESO では、マニフェスト内で明示的な認証情報（`jwt` や `secretRef` 等）を指定しない場合、AWS SDK のデフォルト認証チェーン経由で Pod Identity の環境変数を自動利用します。

以下は、ECR トークンを 1 時間ごとに自動生成・更新し、`dockerconfigjson` 形式の Kubernetes Secret として同期する設定例です：

```yaml
apiVersion: generators.external-secrets.io/v1alpha1
kind: ECRAuthorizationToken
metadata:
  name: ecr-token-generator
  namespace: default
spec:
  region: ap-northeast-1
---
apiVersion: external-secrets.io/v1beta1
kind: ExternalSecret
metadata:
  name: ecr-docker-secret
  namespace: default
spec:
  refreshInterval: "1h"
  target:
    name: ecr-registry-secret
    template:
      type: kubernetes.io/dockerconfigjson
      data:
        .dockerconfigjson: '{"auths":{"<YOUR_ACCOUNT_ID>.dkr.ecr.ap-northeast-1.amazonaws.com":{"username":"{{ .username }}","password":"{{ .password }}"}}}'
  dataFrom:
  - sourceRef:
      generatorRef:
        apiVersion: generators.external-secrets.io/v1alpha1
        kind: ECRAuthorizationToken
        name: ecr-token-generator

```


これで、自動的に ECR 認証用 Secret (`ecr-registry-secret`) が生成・維持されます。Helm やイメージ取得処理からはこの Secret を参照して利用します。
