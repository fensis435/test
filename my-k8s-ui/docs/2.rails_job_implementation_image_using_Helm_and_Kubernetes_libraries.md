# Helm と Kubernetes ライブラリを使った Rails 側ジョブ実装イメージ

Helm（CLI）でのインストール／アンインストールと、Kubernetes API（kubeclient gem）での Start／Stop／Restart を組み合わせた Job クラスのサンプルです。

---

## 依存ライブラリ

Gemfile に以下を追加してください。

```ruby
gem 'kubeclient'
gem 'json'
```

Helm 呼び出しは CLI を利用し、Ruby の `Open3` でラップします。

---

## Helm ラッパークラス（lib/helm.rb）

```ruby
# lib/helm.rb
require 'open3'

class Helm
  def initialize(namespace:)
    @namespace = namespace
  end

  # helm install <release> <chart> --namespace <ns> --wait --timeout 300s
  def install(release_name, chart_path, values: {})
    cmd = ['helm', 'install', release_name, chart_path,
           '--namespace', @namespace,
           '--wait', '--timeout', '300s']
    values.each { |k,v| cmd << '--set' << "#{k}=#{v}" }
    stdout, stderr, status = Open3.capture3(*cmd)
    raise stderr unless status.success?
    stdout
  end

  # helm uninstall <release> --namespace <ns>
  def uninstall(release_name)
    stdout, stderr, status = Open3.capture3(
      'helm', 'uninstall', release_name, '--namespace', @namespace
    )
    raise stderr unless status.success?
    stdout
  end
end
```

## Kubeclient の初期化（config/initializers/kubeclient.rb）

```ruby
require 'kubeclient'

ssl_opts = { verify_ssl: OpenSSL::SSL::VERIFY_NONE }
auth_opts = { bearer_token: ENV['K8S_BEARER_TOKEN'] }

# apps/v1 用クライアント（Deployment 操作用）
$k8s_apps_client = Kubeclient::Client.new(
  'https://kube-api.example.com/apis/apps/v1',
  'v1',
  ssl_options: ssl_opts,
  auth_options: auth_opts
)
```

## ジョブクラス例

### 1. InstallJob

```ruby
# app/jobs/install_job.rb
class InstallJob < ApplicationJob
  queue_as :default

  def perform(operation_id)
    op = Operation.find(operation_id)
    op.update!(status: 'processing', progress: 10)

    helm = Helm.new(namespace: op.app.namespace)
    helm.install(op.app.name, op.app.chart_path)
    op.update!(progress: 50)

    # Deployment のローリングアップデート進捗をポーリング
    loop do
      dep      = $k8s_apps_client.get_deployment(op.app.name, op.app.namespace)
      desired  = dep.spec.replicas
      updated  = dep.status.updatedReplicas || 0
      percent  = [(updated.to_f / desired * 50 + 50).to_i, 100].min
      op.update!(progress: percent)
      break if updated >= desired
      sleep 5
    end

    op.app.update!(status: 'running')
    op.update!(status: 'idle', progress: 100)
  end
end
```

### 2. UninstallJob

```ruby
# app/jobs/uninstall_job.rb
class UninstallJob < ApplicationJob
  queue_as :default

  def perform(operation_id)
    op = Operation.find(operation_id)
    op.update!(status: 'processing', progress: 0)

    Helm.new(namespace: op.app.namespace).uninstall(op.app.name)
    op.update!(progress: 100)

    op.app.destroy!
    op.update!(status: 'idle')
  end
end
```

### 3. StartJob

```ruby
# app/jobs/start_job.rb
class StartJob < ApplicationJob
  queue_as :default

  def perform(operation_id)
    op = Operation.find(operation_id)
    op.update!(status: 'processing', progress: 0)

    # replicas を 1 にスケール
    patch = { spec: { replicas: 1 } }
    $k8s_apps_client.patch_deployment(op.app.name, patch, op.app.namespace)

    op.update!(progress: 100)
    op.app.update!(status: 'running')
    op.update!(status: 'idle', progress: 100)
  end
end
```

### 5. RestartJob

```ruby
# app/jobs/restart_job.rb
class RestartJob < ApplicationJob
  queue_as :default

  def perform(operation_id)
    op = Operation.find(operation_id)
    op.update!(status: 'processing', progress: 0)

    # kubectl rollout restart 相当のアノテーションパッチ
    annotation = { "kubectl.kubernetes.io/restartedAt" => Time.current.utc.iso8601 }
    patch      = { spec: { template: { metadata: { annotations: annotation } } } }
    $k8s_apps_client.patch_deployment(op.app.name, patch, op.app.namespace)
    op.update!(progress: 50)

    # 可用レプリカ数をポーリング
    loop do
      dep      = $k8s_apps_client.get_deployment(op.app.name, op.app.namespace)
      avail    = dep.status.availableReplicas || 0
      desired  = dep.spec.replicas
      percent  = [(avail.to_f / desired * 50 + 50).to_i, 100].min
      op.update!(progress: percent)
      break if avail >= desired
      sleep 5
    end

    op.update!(status: 'idle', progress: 100)
  end
end
```

### 解説

- **Helm install/uninstall**  
  - CLI を `Open3` で呼び出し、`--wait` オプションでリリース完了まで待機  
  - 進捗は後続の K8s デプロイ状況をポーリングして算出
- **Start/Stop**  
  - `kubeclient` で Deployment の `replicas` を直接パッチ  
  - 単一リクエストで完了と判断し、100% に更新
- **Restart**  
  - PodTemplate のアノテーションを更新し、ローリング再起動をトリガー  
  - 新旧 Pod の `availableReplicas`
